## What I've built

### [Grade Lab](https://github.com/callumtsungu200-coder/Grade-Lab) · [live](https://gradelab.netlify.app)
A GCSE revision platform covering 12 subjects, with 4,700+ flashcards and 4,900+ exam-style questions matched to each exam board's specification. It has spaced repetition, auto-marked quizzes, an in-app past-paper viewer, accounts with cloud sync, Stripe subscriptions and an offline-capable PWA.
`React` `TypeScript` `Supabase` `Postgres` `Stripe` `Netlify Functions` `Vitest`

### [Personal portfolio](https://github.com/callumtsungu200-coder/chris-tsungu-portfolio-) · [live](https://chris-c-tsungu.netlify.app)
A multi-page site with project case studies, a CV page generated from the same typed data and a validated contact form.
`React` `TypeScript` `Tailwind CSS` `Framer Motion` `React Router`

### [Bluff](https://github.com/callumtsungu200-coder/bluff)
A 3D version of the card game Bluff (also called Cheat) against three computer opponents with different personalities. The rules engine is pure, tested JavaScript, separate from the WebGL scene.
`React` `Three.js` `React Three Fiber` `Zustand`

### Client websites
I've designed, built and sold sites to two businesses: [MO BARBER](https://mo-barber.com/), a barbershop in Colchester, and [Brows by Deja](https://browsbydeja.netlify.app/), a brow studio in Akron, Ohio.
